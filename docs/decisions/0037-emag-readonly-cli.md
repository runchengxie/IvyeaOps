# ADR-0037：eMAG 采集使用独立只读 CLI

日期：2026-10-28

## 背景

外部 Agent 已能通过 MCP 使用本地快照和报告，但没有可重复运行的官方商品数据来源。需要使采集可脱离网页运行，同时避免把卖家密码、真实资料或本机认证绕过配置发布到 fork。

## 决策

增加 eMAG RO 固定只读端点 CLI，完成分页后通过现有 store_artifacts 导入。Windows 默认精确读取一条普通凭据；其他环境使用显式交互输入。采集不会自动新增 MCP 权限或修改网页登录行为。

## 理由与后果

使用标准 Windows 接口不新增密码库依赖；不将密码写入 .env 或命令行参数。相比直接把完整 REST API 包装为 MCP，当前端点和权限范围更窄。先按需运行，不新增调度器或模型 Harness。

部分采集不导入，避免把失败当作店铺数据减少。字段投影限制嵌套文档和附件信息，代价是复杂审核错误仍需在卖家后台核实。沿用 2 MB 文件上限，大店铺未来需要明确设计分页证据存储，不能静默截断。

同一 Windows 用户下的进程可能读取该凭据；当前一次支持一个 RO 账号。此功能不提供无人值守服务账号配置、多个店铺身份验证或任何平台写操作。
