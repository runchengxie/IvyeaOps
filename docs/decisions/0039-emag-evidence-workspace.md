# ADR-0039 · eMAG 页面复用快照，无头运行与模型解耦

- 日期：2026-10-28
- 状态：已采纳

## 背景

原默认业务页依赖 Amazon 数据源，PNK 不应传入 ASIN 工具。店铺巡检已经具备只读采集及版本化证据，但每次需要串联多条命令。用户希望专注 eMAG、尽量无头，并明确选择先手动运行。

## 决策

默认业务页共用 eMAG RO 快照、本地草稿和人工处理记录，原平台能力置于明确 legacy 路径。统一 CLI 串联只读采集、字段增量、绑定报告和运行回执；外部 agent 通过 read-scoped MCP 查询回执。任务台的模型不成为运行前置条件。不注册定时任务，不增加平台写接口。

## 理由与后果

现有可验证证据可以立即支持本店商品管理，不能支持全市场搜索量、竞争份额或利润结论。选择标注缺口而不重命名旧数据源。快照锁保证草稿保存不会跨版本；每店任务锁避免同入口并发采集。SQLite/本地文件无新依赖，进程崩溃仍需凭回执时间排查。未来实写接口需要单独验证平台契约、授权、幂等和执行回读。
