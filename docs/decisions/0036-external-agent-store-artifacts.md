# ADR-0036 · 外部 Agent 通过 MCP 使用店铺证据与巡检报告

- 日期：2026-10-28
- 状态：已采纳（本地 fork）

## 背景

独立机器上的工作台需要供多个外部 Harness 使用。强制使用内置模型会重复维护对话与模型配置，而直接暴露全部管理接口会让工具权限过宽。当前没有经过验证的 eMAG 实时数据接入。

## 决策

复用现有 MCP 服务和令牌，先增加读取显式导入快照、保存和读取本地报告三个窄工具。外部 Agent 负责分析，工作台负责证据、报告和审计。保留原模型路径，尚不改造所有内部 AI 功能。

## 理由与后果

无需生产环境新增 SDK 依赖，也不要求模型密钥。快照必须携带时间、来源和范围，保存报告时内嵌快照，防止后续导入覆盖证据。代价是第一阶段需显式导入资料、报告暂通过 MCP/CLI 读取，未新增网页报告浏览器。标准客户端兼容性用开发环境 MCP SDK 验证；其余 Harness 仍需实测。
