# eMAG 能力对照

[English](../emag-capability-map.md)

这里描述当前 fork 的实现，不代表 eMAG Marketplace API 的全部能力。现有采集面向 eMAG RO，并生成本地证据；仍需要平台权限和允许的出口 IP。

[eMAG API 介绍](https://marketplace.emag.ro/infocenter/emag-academy/how-to-add-a-product/product-import-through-api-or-feeds/?lang=en)说明平台支持商品和报价刊登、库存与价格更新以及订单处理。平台支持这些能力，不代表本 fork 已实现它们，也不代表特定卖家账号已经获得相应权限。

| 领域 | 当前可用 | 边界 |
|---|---|---|
| 商品 | 读取部分字段，检查分页完整的快照 | 不提交商品或 offer |
| 订单和退货 | 读取部分自发货/FBE 数量及带来源记录 | 不执行接单、履约或退款 |
| 库存和价格 | 查看已采集字段；独立可选的单商品价格API | 不同步库存、不自动调价或提供已核实利润；见[价格API](emag-write-readiness.md) |
| 本地运营 | 创建绑定快照的草稿、方案和人工执行记录 | 批准与执行记录不会调用平台写接口 |
| 报告与智能体 | 创建手动回执和本地报告；通过有权限的 MCP 工具读取证据 | 仍需 token 和管理员权限；不暴露密码或通用 eMAG 写代理 |
| 定时 | 按服务器时间预览计划并导出停用草稿 | 当前没有调度器消费 eMAG 草稿 |
| 调研和翻译 | 查看自有商品目录；配置服务后可翻译图片 | 自有目录分布不等于市场需求或竞品销量 |

fork仍保留亚马逊专用API、旧页面、技能和后台任务，下线前需盘点消费者、已有数据与迁移路径。独立价格API默认关闭，真实权限及具体修改值仍需核实；商品资料、库存及订单写入仍未实现。

## 逐步聚焦 eMAG

1. 盘点每个旧路由、API、CLI、技能和已有 artifact 的消费者。
2. 根据已验证的 eMAG 数据和平台能力对照所需流程，记录缺口和权限。
3. 准备数据保留和迁移说明，再向实际消费者说明弃用安排。
4. 消费者完成迁移且替代能力验证通过后，才退役对应旧功能。

以上是评估步骤，不代表所有平台操作已经得到支持。

实现和限制详见[架构](architecture.md)、[使用](usage.md)和[英文代码审计](../code-audit-2026-10.md)。
